# Hermes assistant training session

Everyone leaves able to ask the assistant something useful on Telegram, send a
document the right way, and knowing what never goes in chat. 45 minutes, all
staff, day 2 afternoon, after everyone is enrolled. Part of
[[24.12 Hermes assistant on-site deployment]].

Attendees bring their phone and laptop, charged, with Telegram and Buzz signed in. Hand
out the quick cards ([[24.12b Hermes assistant quick cards]]) at the door.

## Run of show

| Time | Block | Format |
| --- | --- | --- |
| 0:00–0:05 | 1. Why we're doing this | Owner speaks, 2 min; you, 3 min |
| 0:05–0:15 | 2. What it can do | Live demo on the projector |
| 0:15–0:22 | 3. What never goes in chat | Talk + live refusal demo |
| 0:22–0:35 | 4. Hands-on | Everyone, on Telegram and Buzz |
| 0:35–0:40 | 5. When it breaks | Talk |
| 0:40–0:45 | 6. Questions + wrap-up | Open floor |

If you run short, cut block 2's demos to one. Never cut block 3 or block 4.

## Talking points

**1. Why we're doing this**

- Owner: the problem it solves here (e.g. "we lose time hunting for files"),
  and that using it is expected.
- You: each person has an agent that knows the company's files. Buzz is the
  hub: everything you send, messages and documents, lands there first and is
  routed to agents and filed. Telegram is your private line to your own agent.
- It works only for enrolled people; each person has their own profile.

**2. What it can do**

Demo three asks in Telegram, using real company files, one per role in the room:

1. Find: "Where's the latest ________?"
2. Summarise: "Summarise ________ in 5 lines"
3. Draft: "Draft a reply to ________ saying ________"

Point out: ask in plain words, follow up in the same chat, check its answer
before you send it on. Then show the same message arriving in Buzz.

**3. What never goes in chat**

- Three tiers: open, internal, restricted. Show the restricted list: ________
- Never in chat: passwords, bank details, ID numbers, health information,
  anything restricted.
- Internal and restricted files go through the upload link only.
- Demo: send a restricted test file in chat; show the refusal and the upload
  link it replies with.
- Sent something by mistake? Tell the admin right away. Nobody gets blamed for
  reporting it.

**5. When it breaks**

- No reply on Telegram in 5 minutes → reach your agent directly in Buzz and
  tell the admin.
- WhatsApp or SMS users: the extra channel can drop; Telegram is your main
  channel.
- The admin is ________. Show where that name is on the card.
- Leaving the company or lost your phone → tell the admin the same day.

## Hands-on (block 4)

Everyone does exercises 1–4. You and the admin walk the room; pair anyone
who is stuck with someone who's finished.

1. **Ask:** one of your role's use cases from your card, on Telegram. Read the
   answer: is it right?
2. **Follow up:** ask a second question that builds on the first ("Make it
   shorter", "Which date is that from?").
3. **Upload:** send the practice file ________ through the internal upload
   link. The admin shows it arriving in Buzz and confirms it was filed in the
   right tier.
4. **Hub:** post in your team's Buzz thread and ask your agent to pick it up.
5. **Extra channel:** WhatsApp and SMS users ask the same question there too.

Done when every person has completed all of them. Note anyone who hasn't and
finish with them right after the session.

## Likely questions

| Question | Answer |
| --- | --- |
| Can my boss read my chats? | Confirm the policy with the owner beforehand: ________ |
| Can it see everyone's files? | It sees the files your role is allowed; restricted files stay in the encrypted vault |
| Is it always right? | No. Check anything you send to a customer or act on with money |
| Can I use it at home or on my phone? | Yes, from your enrolled Telegram account. Work files only, same rules |
| Can I upload personal documents? | No. Company files only |
| What if I accidentally send something restricted? | Tell the admin straight away; they'll remove it. No blame for reporting |
| Can I use a different Telegram account? | Only the account enrolled for you gets answers; ask the admin to change it |
| Who do I ask for help? | The admin, ________ |

## Prep + wrap-up

**Before the session**

- [ ] Everyone enrolled and passed round-trip tests (Day 2 AM log)
- [ ] Quick cards printed, blanks filled, sorted by channel
- [ ] Projector showing Telegram Desktop and the Buzz hub side by side
- [ ] Three demo asks rehearsed against real files
- [ ] Restricted test file and practice upload file ready
- [ ] Owner briefed on their 2 minutes and the chat-privacy answer
- [ ] Admin present to confirm uploads and help in block 4

**Wrap-up (last 2 minutes)**

- Repeat the three rules: plain words, nothing restricted in chat, everything
  goes through Buzz.
- Name the admin and the support window: ________
- Announce the 2-week check-in: ________

**After**

- [ ] Finish hands-on with anyone who didn't complete it
- [ ] Log questions you couldn't answer; send answers within 2 days
