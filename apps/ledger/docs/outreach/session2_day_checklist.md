# Session-two day checklist — the accrual-economics machinery

*Companion to `charter_session2_agenda.md`, same split as charter day: the agenda
owns the decisions; this checklist owns what makes them signable. Session two's
day has a sharper gate and a heavier rehearsal load than session one's. The gate:
**"before the first thing bills" is a checkable fact, not a vibe** — if anything
has already billed or accrued, the room is late, and that gets surfaced at the
top, never papered over. The rehearsals: this agenda carries THREE live
demonstrations, and each one is the session's argument in miniature — the
forward-only demo especially, because "you are not carving stone tonight" is only
comforting if the room watches it be true.*

---

## 0 — Preconditions

- [ ] Charter day closed: session one's constants and key ceremony on the log,
      checkpoint published, minutes out
- [ ] **The gate, verified from the log**: zero billing events, zero patronage
      accruals on the real log — the constants-before-first-evaluation rule is
      about to be honored, provably. If anything already accrued under the
      placeholder rule: STOP, surface it to the room as the first agenda item —
      what accrued, under which flagged rule, and what session two's decisions
      mean for it (forward-only protects the history either way; the room
      decides with eyes open)
- [ ] Pre-reads out with the convening notice: the value equation (one page),
      the placeholder rule in plain words, "dues are not patronage" (three
      sentences)
- [ ] The membership roll current — who may vote tonight is session one's
      admission flow answering its first real question

## 1 — The week before: three demos and a signing, all rehearsed

- [ ] **Demo A (the habit):** session one verified from a MEMBER'S copy — a
      volunteer member's own instruction sheet, their device if possible; two
      minutes; rehearsed with that member beforehand
- [ ] **Demo B (the forward-only comfort):** on the test log — accrue under v1,
      activate a changed rule, show the old entries byte-identical and the new
      credits under the new rule id. This demo IS the session's thesis;
      rehearse until it's boring
- [ ] **Demo C (the machinery):** a patronage event lands → balance query
      answers → a redemption schedule's shape shown — test log, scripted,
      timed
- [ ] **The signing dry run**, scratch store, decision-sheet order:
      `AccrualRuleActivated` (kinds + weights) · `CharterConstantDeclared` for
      each eligibility decision, the redemption standard terms, the I1 trigger ·
      checkpoint. Timed to the agenda's 20 minutes; rejection alternates
      rehearsed
- [ ] The decision sheet printed, session-two edition: the kinds table with
      reserve/reject columns · weights + default blank · the three eligibility
      questions (probationary / cure / hardship) each with the software's
      current flagged answer PRINTED beside the blank · redemption standard
      terms with blanks · the I1 trigger line. **Defaults-if-undecided
      pre-filled: undecided stays closed** (an undeclared kind doesn't exist;
      an unset weight doesn't accrue)

## 2 — Room setup

- [ ] Test log and real log VISIBLY separate machines/prompts — the room must
      never wonder which one just changed (label them; say it)
- [ ] The run-sheet posted: demos A/B/C cues + the signing sequence
- [ ] Printed per seat: the pre-reads · the decision sheet · the verification
      instruction sheet (same paragraph as session one — the habit is the
      institution)
- [ ] The zakāt answer ready if asked beyond item 6's five minutes: per-member,
      member-sovereign, computed on request, nobody else ever sees it — and no
      demo of anyone's actual fold, ever, including a volunteer's

## 3 — During: the chair's discipline (session-two additions)

- [ ] Founder chairs, votes once — restated at the open, same as always
- [ ] "Dues are deliberately absent" said aloud at item 2, in the room's
      hearing, before the kinds vote — the ⊥ is a design promise, and tonight
      is when members learn it's load-bearing
- [ ] Item 3's honesty note read AS WRITTEN: the eligibility decisions live as
      flagged code semantics; tonight's events are the authority; code aligns
      in follow-ups citing tonight; **if code and charter ever disagree, the
      charter event wins and the mismatch is a defect**
- [ ] Item 5 discipline: the room sets the TRIGGER, not the number — if the
      ratio conversation ignites anyway, the chair parks it by reading the
      trigger text back ("whoever's here then decides it")
- [ ] Timeboxes real; blown ones land as printed defaults; objections recorded
      verbatim

## 4 — The signing

- [ ] Decision-sheet order, each append confirmed accepted before the next
- [ ] `AccrualRuleActivated` carries exactly the kinds and weights the sheet
      shows — read the payload aloud before it appends; this is the one event
      members will feel in their balances
- [ ] Checkpoint emitted and published off-machine while the room watches
- [ ] Instruction sheets handed out again — repetition is the point
- [ ] Scratch/test data confirmed nowhere near the real log (the paranoia item,
      inherited)

## 5 — After the room empties

- [ ] **The code-alignment follow-ups filed SAME WEEK**: one change per item-3
      decision, each citing its charter event reference, plan-first like every
      change in this repo — the honesty note's promise has a clock on it,
      because every day of drift is a live code-vs-charter mismatch
- [ ] Minutes = decision sheet + event references, to every member
- [ ] Counsel sync: the accrual and redemption constants forwarded so the
      entity documents keep saying the same thing as the log
- [ ] The I1 trigger diarized where it will actually fire: whoever runs the
      Face's go-live checklist inherits "ratio declared before the first
      routed load" as a blocking precondition
- [ ] Session-three triggers restated in the minutes (per program, as each
      wakes) — and the misses-first debrief written same-day: the demo that
      stumbled, the weight debate that needed data nobody had, the default
      that landed by clock
