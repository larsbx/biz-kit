# 03_LADDER.md — Capital Sequencing & Evidence Gates

Register: business/system terms (01). Concern: when capital commits. Constraint: 00 Art. IV.3 (capital follows evidence).

---

## 1. Tiers

```
T0  software on existing exhaust     κ ≈ 0                 value at n = 1
T1  coordination, no balance sheet   κ = bond + software    value at small n
T2  other people's assets            κ = deposits ≤ L_max   value where folds prove demand
T3  owned (LandCoop)                 κ = share capital      value where T2 proves income
```
Monotone: no tier's capital commits before the prior gate passes. Gate-skipping is forecast-underwriting — forbidden.

## 2. Contents

**T0** — back-office automation; detention recovery (often ≥ dues alone); coverage sentinel; facility intelligence at G0–G1; renewal/endorsement automation. All folds over exhaust the member already emits.

**T1** — Broker Face (04): the largest value line at near-zero capital — no motor-carrier authority or safety score, no operational control of power units (the broker's own bond, payment, carrier-selection, and contractual liability surfaces remain); door-to-door sold with uncontrolled stages subcontracted bilaterally. Group purchasing (insurance stage 0, fuel, tires, parts). Backhaul matching on the aggregate lane graph. Netting first, benevolent loans small — cheapest capital is capital never moved.

**T2** — leased capacity per 07 §4, demand pre-committed by signed pledges before signature; term preference per-drop ≻ short master ≻ long master. Fleet: per-graduation, deal-funded (05); no speculative pool — no pool predicate exists.

**T3** — per-parcel, income-backed: realized T2 rent underwrites acquisition; share raises against demonstrated income.

## 3. Gates (charter constants; log-pure)

```
G₀→₁ : active_members ≥ m₁ ∧ engagement_fold ≥ e₁
G₁→₂ : ∀ target f: utilization_fold(f) ≥ u_min ∧ Σ pledges(f) ≥ d_min(f)
        ∧ Σ obligations + pv(f) ≤ L_max
G₂→₃ : realized_utilization(f, w) ≥ u_own ∧ rent_fold(f) ≥ r_min
        ∧ NAV headroom ≥ price(f)
Fleet : bound graduation candidate per unit
```

## 4. Value matrix (class × tier)

| Class \ Tier | T0 | T1 | T2 | T3 |
|---|---|---|---|---|
| Carrier | back-office, detention $, coverage sentinel | retained broker margin, backhaul, group buying | staged capacity at member rate | equity NAV, yard moat |
| Graduating driver | — | sponsorship visibility, netting | lease-to-own unit (per-deal) | owner-operator with stake |
| Shop | work-order automation | parts buying, referral flow | leased bays at card | facility equity |
| Service co-op worker | dispatch automation | member-rate volume | fleet maintenance contracts | equity |
| Property-owner | graded listing | lease income | contribution-for-shares | appreciation + rent |

Recruitment cost ≈ 0 marginal: the stake view renders accreting equity from T0–T1 margins.

## 5. Properties

```
P1  tier transitions carry the fold hash they were evaluated on
P2  T2 lease without G₁→₂, or T3 acquisition without G₂→₃, is unrepresentable
P3  fleet units bind to named candidates; a pool is unrepresentable
P4  constants declared before first evaluation; retro-fit void
P5  T0/T1 lines impose no fixed liability
```
