# Charter session template — for when a program wakes

*Sessions three and onward are not scheduled; they are TRIGGERED — one session per
program, when its first evaluation nears. Copy this template per session, fill the
program line, and hold the posture it enforces: a program goes live only behind four
locks — **constants declared ∧ counsel cleared ∧ evidence gate true ∧ rulings where
contested** — and a session that adjourns with the program still asleep because a lock
held is a SUCCESS. Gate-skipping is forecast-underwriting, and forecast-underwriting is
forbidden (corpus 03 §1). Same room rules as always: 1M1V, timeboxes, undecided stays
closed, forward-only fixes.*


---

## 0 — Why we're here, from the log *(10 min)*

The waking trigger shown live from the folds — not asserted, queried. *"We are here
because the log says ____."* If the log doesn't say it, adjourn now with thanks: the
evidence gate is the member's protection against enthusiasm, including this room's.

## 1 — The owning law, read *(20 min)*

The program's corpus section, aloud or summarized faithfully (its register noted — the
glossary bridges, 01). What the design already fixed vs what it left to this room.
Purpose-preserving refinement is allowed; silent drift is void (00 Art. I.1, VII).

## 2 — Counsel lock *(10 min)*

The program's Tier-3 items from `docs/counsel_briefing.md` — status of each. **Machinery
may exist; use may not**: an unanswered counsel item keeps the external surface closed
regardless of tonight's votes. If counsel isn't engaged yet, tonight's signing includes
the engagement decision, and the program sleeps on.

## 3 — Contested-at-N inventory *(15 min)*

Which of the program's instruments are contested (09's findings register knows):
each enters live use at **N — unrepresentable — until a ruling event exists**. If this
is the FIRST program needing a ruling: the ruling-organ question (09 §5 — composition,
appointment) is forced tonight and is its own decision, bigger than the program.

## 4 — The constants *(the long middle — decide)*

From the 04 §9 registry, the program's slice only:

| constant | meaning (plain words) | proposed | default if undecided |
|---|---|---|---|
| | | | the program stays asleep |
| | | | |

Every value here is evaluated by a pure function of the log the moment it's declared —
no one applies these; they apply themselves. Declare conservatively; forward revision
is visible and cheap.

## 5 — Evidence review *(20 min)*

The folds the program's gate evaluates, shown live and read together (utilization,
pledges, coverage, whatever this gate needs). Not to argue with them — to make the room
fluent in the numbers that will open and close this program without asking anyone.

## 6 — Autonomy & safeguards *(20 min)*

The program's new acts, each assigned per the doctrine (10): human-signature classes →
R · contested → N · inside a signed envelope → A · unclassifiable → block, and block is
fine. For every externally-visible A act: its envelope, its guard, its **compensator**
named tonight. New role keys or capability grants: declared here, multi-holder where it
matters.

## 7 — The signing *(20 min)*

Constants → `CharterConstantDeclared` · rules → the program's `*RuleActivated` where it
has one · keys/capabilities → `RoleKeyDeclared` · counsel-engagement and
ruling-referral decisions recorded · checkpoint emitted and **published while the room
watches** · the verification sheet, every time — the habit is the institution.

## 8 — Close: the wake condition, restated *(5 min)*

```
this program is LIVE when:  [ ] constants (tonight)   [ ] counsel (item 2 status)
                            [ ] evidence gate true    [ ] rulings where contested
```
Whichever boxes stay open, the program sleeps until they don't — and nobody needs to
reconvene to *stop* anything, because nothing starts by itself.
