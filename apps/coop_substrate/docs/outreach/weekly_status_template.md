# Field-phase weekly status — template

*Fifteen minutes, same day each week. Copy per week; names never appear here (aggregates
only), so completed reports may live in the repo or the private dir — your call. The
discipline: **facts are pasted from commands, never remembered**; judgment gets its own
section and stays short. A solo operator's real risk isn't lying to others — it's
drifting quietly. This is the anti-drift ritual.*
