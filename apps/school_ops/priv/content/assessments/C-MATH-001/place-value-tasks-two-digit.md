# Place-value tasks: two-digit form PV2

- Part of assessment: A-MATH-001-02; form PV2
- Intended learners: 2nd grade; use after the relevant ones/tens work
- Status: draft
- Scope: ones/tens and values within 99
- Materials: paper, pencil, objects or base-ten blocks, place-value chart; no calculator

Directions may be read aloud. You may use objects, drawings, or spoken answers.
Give a reason when asked. For a stated number of counting terms, include the
starting number as the first term. Include both endpoints when counting between
two numbers.

## Tasks

| Item | Task |
| --- | --- |
| PV2-01 | Model 47. Name the unit you are counting and show the amount contributed by each digit. |
| PV2-02 | Model 34 with tens and ones. Exchange one ten for single ones. Show the new groups and explain what amount stays unchanged. |
| PV2-03 | Model 50 and 80. Explain the zero position in each numeral. |
| PV2-04 | Count by ones from 67 through 71. Show or explain what happens to the groups when you pass from 69 to 70. |
| PV2-05 | Starting at 15, give five terms while counting by fives. State the step. |
| PV2-06 | Starting at 23, give five terms while counting by tens. Explain which grouped amount changes and which ones stay the same. |
| PV2-07 | Read 72, express it as a sum of place values, and model the same amount. Explain how the written places match your model. |
| PV2-08 | Write eighty-six as a numeral and a sum of place values. |
| PV2-09 | Write, name, and express as a sum of place values the amount formed by three tens and no additional ones. |
| PV2-10 | Insert a symbol: 64 __ 46. Explain the comparison using the relevant units. |
| PV2-11 | Insert a symbol: 38 __ 42. Explain the comparison using the relevant units. |
| PV2-12 | Insert a symbol: 55 __ 55. Explain. |

The teacher keeps the answer guide separate. This form does not check hundreds
or the 1,000 extension. Individual work belongs in private records.
