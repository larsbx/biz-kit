# Place-value tasks: three-digit form PV3

- Part of assessment: A-MATH-001-02; form PV3
- Intended learners: 2nd grade; use after the relevant ones/tens/hundreds work
- Status: draft
- Scope: ones/tens/hundreds and values within 999
- Materials: paper, pencil, objects or base-ten blocks, place-value chart; no calculator

Directions may be read aloud. You may use objects, drawings, or spoken answers.
Give a reason when asked. For a stated number of counting terms, include the
starting number as the first term. Include both endpoints when counting between
two numbers.

## Tasks

| Item | Task |
| --- | --- |
| PV3-01 | Model 374. Name the unit you are counting and show the amount contributed by each digit. |
| PV3-02 | Model 264. Exchange one hundred for tens, then one ten for single ones. Show the groups after each exchange and explain what amount stays unchanged. |
| PV3-03 | Model 507 and 300. Explain every zero position. |
| PV3-04 | Count by ones from 397 through 401. Show or explain the regrouping when you pass from 399 to 400. |
| PV3-05 | Starting at 45, give five terms while counting by fives. State the step. |
| PV3-06 | Give five terms by tens starting at 280, then five terms by hundreds starting at 200. State each step. |
| PV3-07 | Read 709, express it as a sum of place values, and model the same amount. Explain how the written places match your model. |
| PV3-08 | Write six hundred thirty as a numeral and a sum of place values. |
| PV3-09 | Write, name, and express as a sum of place values the amount formed by three hundreds, eight tens, and no additional ones. |
| PV3-10 | Insert a symbol: 648 __ 684. Explain the comparison using the first differing place. |
| PV3-11 | Insert a symbol: 503 __ 480. Explain the comparison using the relevant units. |
| PV3-12 | Insert a symbol: 720 __ 720. Explain. |

The teacher keeps the answer guide separate. This form does not require the
optional [1,000 extension](place-value-tasks-1000.md). Individual work belongs in
private records.
