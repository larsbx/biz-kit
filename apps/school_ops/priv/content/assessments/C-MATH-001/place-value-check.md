## Administration

The linked task sheets contain original school-ops questions without teacher keys
or links to this answer guide. Their non-clickable assessment ID preserves the
connection to this teacher record. Distribute a standalone copy or export of only
the chosen learner sheet and any blank chart; keep this guide and lesson keys out
of view during the check. Repository navigation exposes teacher material, so use
the learner copy for administration.
Read directions without explaining the answer. Where a number of counting terms
is requested, the starting value is the first term; range endpoints are included.

The forms use different application examples from the lesson practice, including
the former 95-by-fives exercise. Basic unit relationships are intentionally taught;
the checks ask for models/reasons and their application to new amounts. If a full
assessment prompt has already been practiced or its key seen, prepare a fresh keyed
application for the same relationship before seeking independent evidence. Merely
hiding a previously seen key does not make the task fresh.

Allow objects, drawings, and spoken explanations. Accept accurate spoken number
names when spelling needs support; customary use of "and" in a number name does
not change its value. Do not impose a speed threshold. Give feedback after the
attempt. Record answer cues or teaching prompts as support, rather than calling
the resulting response independent.

## Optional 1,000 teacher key

| Item | Teacher key or model evidence |
| --- | --- |
| PVX-01 | Each hundred represents 100 ones, so ten hundreds represent 10 × 100 = 1,000 ones. Exchanging those groups for one thousand preserves that amount; no ones are added or removed. Numeral: 1,000; name: one thousand; place-value sum: 1,000 (or 1,000 + 0 + 0 + 0). The model/chart has one thousand, zero hundreds, zero tens, and zero ones; four digit positions, with the comma only a separator |
| PVX-02 | 996, 997, 998, 999, 1,000; at 999 to 1,000, ten ones become one ten, ten tens become one hundred, and ten hundreds become one thousand |

1,000 is a four-digit numeral. PV3 comparison tasks use three-digit values only;
the optional extension does not claim four-digit comparison coverage.

## Outcome criteria

These are proposed local teaching criteria, applied separately to the selected
form and taught scope. Check every part of a multi-part item. A correct answer
alone is insufficient when the task also asks for a reason or model.

| Course outcome | Core items | Proposed evidence to progress in the checked scope |
| --- | --- | --- |
| O-MATH-001-001 | PV2/PV3 items 01–03 and the boundary composition in item 04 | All models and digit amounts correct; name the counted unit, explain unpacking and each zero position. In item 04, demonstrate composing ten ones into one ten (PV2), or ten ones into one ten and then ten tens into one hundred (PV3), preserving the amount after adding the next one |
| O-MATH-001-002 | PV2/PV3 items 04–06 | Complete sequences correct, including endpoints/starting terms; identify each step and explain the boundary exchange in item 04 |
| O-MATH-001-003 | PV2/PV3 items 07–09 | All numeral, name, and place-value conversions correct; connect item 07 to its model |
| O-MATH-001-004 | PV2/PV3 items 10–12 | All comparisons and symbols correct; justify the first differing place or equality |

| Optional extension coverage | Items | Proposed evidence |
| --- | --- | --- |
| O-MATH-001-001: thousand grouping | PVX-01 and the exchange explanation in PVX-02 | Explain preservation of the amount when ten hundreds become one thousand and the resulting zero lower positions |
| O-MATH-001-002: count through 1,000 | PVX-02 | All five terms correct; explain the boundary exchange |
| O-MATH-001-003: thousand representation | PVX-01 | Correct numeral, name, place-value sum, and four-position model |

Across each group, inspect grammar (names and representations), logic (the reason),
and rhetoric (an explanation another person can follow). Keep judgments separate
by relationship and form: independent, demonstrated with support, needing review,
or not assessed. Do not replace these judgments with one total score.

Item 04 supplies composition evidence for outcome 001 as well as counting evidence
for outcome 002. Check both parts: a correct recited sequence alone does not
demonstrate composition, and a correct exchange alone does not complete the count.

When evidence is incomplete, revisit the relevant lesson and reassess with fresh
keyed examples in the taught scope. Larger-range work remains pending until taught
and checked. Keep individual evidence privately and use curriculum observations
to revise pacing.
