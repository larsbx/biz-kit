# Khan Academy mathematics workflow

Khan Academy supplies modern practice for goals chosen through the
[Trivium and Quadrivium](trivium-quadrivium.md). The curriculum's structure and
progression are maintained here, along with reasons, demonstrations, and evidence.

## Select practice

1. Choose a mathematical relationship and course outcome.
2. Request questions in a dedicated Khan Academy interaction. Use a grade limit
   explicitly selected by the user; our first course is 2nd grade.
3. Review starting skills, notation, difficulty, and fit to the intended work.
4. Create a [resource record](../templates/resource.md) from actual returned
   metadata, with the query, intended roles, audience, and art and practice. Check
   access and availability and record the dated suitability review.
5. Complete the [resource readiness checks](curriculum-model.md#resource-readiness),
   record the supporting review pull request, mark the resource `ready`, and add
   it to the register. Link consuming lessons when they are authored; registration
   does not depend on lesson readiness. Assessment use also requires a linked ready
   assessment design. Keep class-specific assignment links privately.
6. Combine practice with a reasoning question and an explanation task. Exercise
   completion is evidence to consider, not a complete judgment of understanding.

The current tool also accepts standards-code search limits, but none is selected
for this curriculum. Apply one only if the user explicitly requests it. Any returned
curricular label is provenance rather than the instructional framework.

## Records and boundaries

Use only actual returned titles, IDs, URLs, and metadata. Mark missing fields as
not reported. Store references and attribution rather than copies of exercise
content. Use a private location for links exposing class or learner details.

Exercise-selection responses follow the tool's interactive rendering rules;
repository discussion and edits take place in a separate interaction. The
[Grade 2 queue](../resources/second-grade-math-searches.md) records retrieved resources
and remaining searches.

This capability retrieves assignable mathematics questions. It does not provide
learner-progress import or automatic curriculum synchronization. The
[2026-10-11 review](reviews/2026-10-11-khan-place-value.md) examined 112 items
across 25 provider-returned pages and approved seven resources for optional
hundreds-route practice, now in the [resource register](../resources/README.md).
Use each resource only after its recorded prerequisites and a delivery/access
check. No whole returned set is verified for a strictly two-digit-only assignment
or the exact thousand extension; retain local practice for those routes.

No classroom assignments or learner results are recorded. General exercise links
do not establish assignment creation. Resource readiness applies only to the
reviewed optional practice role; course, unit, lesson, and assessment records
remain draft. Provider completion does not establish mastery. Astronomy
investigations need actual sky material beyond generic mathematics practice.
