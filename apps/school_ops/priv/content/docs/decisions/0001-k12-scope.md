# 0001 — K–12 curriculum scope

- Decision date: 2026-10-08 (America/Chicago)
- Status: accepted scope decision
- Repository: `larsbx/school-ops`

## Decision

Use `school-ops` to develop and organize our K–12 curriculum. The user selected
K–12 as the initial learner scope.

Organize material by subject, course, unit, and lesson. Connect learning outcomes
to prerequisites, resources, assessments, and weekly plans. Use GitHub issues
and pull requests to develop and review the material.

Use the connected Khan Academy capability for requested mathematics exercise
selection. Record reviewed source references in the curriculum resource register.
