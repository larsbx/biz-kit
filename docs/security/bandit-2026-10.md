# Bandit listener security correction (issue #152)

## Scope and dependency decision

Bandit 1.13.1 is affected. The smallest published fixed release as inspected on
2026-10-27 is **1.14.0**. The shared lock must resolve exactly that version.
FederationService and Eatsbot require `~> 1.14.0`; Eatsbot's previous
`~> 1.13.1` excluded the fix. Dispatch and SpruceGoose's existing `~> 1.12`
constraints already permit it. No HTTP routes or authority code are changed.

## Dependabot #145 reconciliation

Inspected head `48acf567adf88bd3288d08d8c62963101da9d573` proposes 21 direct
updates but actually changes **34 lock entries**, including transitive updates.
It leaves Bandit at **1.13.1** and Eatsbot at `~> 1.13.1`. Its unchanged entries
for Bandit's five dependencies are compatible with 1.14.0. Keep #145 separate;
retain this PR's Bandit lock entry and Eatsbot constraint when rebasing it.
A future refresh must pass the same audit and federation tests. Do not merge an
old lockfile wholesale over the correction.

## Acceptance and limitations

Acceptance is pending until actual tests on the correction are recorded below.
The isolated harness uses the same shared lock and production Node listener,
ephemeral CA-verified HTTPS, independent BEAM processes and signed actor requests.
The new raw TLS probes cover malformed framing, large decimal headers inside
the header limit, conflicting Content-Length / Transfer-Encoding, malformed
chunks and CR/LF extensions, oversized fixed/chunked bodies, one-byte chunks,
multipart rejection, signed replay, body tampering and public route smoke.
Existing tests cover actor substitution, current-key rotation, moderation,
restart, withdrawal and seller-home authority boundaries.

HTTP/2 remains disabled; header, connection, body, request and rate limits remain
in place. These are additional mitigations. This is bounded regression coverage,
not a proof of absence of denial-of-service, reverse-proxy desynchronization or
all future advisories. The opt-in explicit-peer pilot is not general Mastodon
conformance. No public deployment is performed by this change.

Rollback: disable the opt-in listener before reverting a dependency correction;
do not expose a rollback to affected 1.13.1. Preserve discovery journals and the
independent seller-home business ledger during rollback.
