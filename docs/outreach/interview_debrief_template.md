# Interview debrief — after each capture day

*Ten minutes, same evening, AFTER the notes template's close-out checklist is done.
Boundaries: the notes template holds what THEY said (findings, verbatim); the weekly
status rolls up the phase; this page holds the one thing neither does — **how the hour
went**: your performance, the instrument's performance, and the judgment calls that
follow from one conversation. Lives in the private dir (it contains judgment about a
named person). Names allowed here; nothing from here touches the log.*
